# معماری (مرحلهٔ ۲)
- **سایت (GitHub Pages):** فایل‌های ثابت. کلید `publishable` Supabase در `backend.js` عمومی و بی‌خطر است.
- **Supabase:** احراز هویت، پایگاه داده با RLS، و تابع سرور `api` (ثبت سفارش، تأیید پرداخت با زرین‌پال، ارائهٔ فصل‌های قفل‌دار).
- **فصل‌های ۳ تا ۸:** فقط داخل جدول `chapter_content` هستند که هیچ سیاست خواندنی ندارد؛ فقط تابع `api` بعد از بررسی خرید آن‌ها را می‌دهد (`chapter.html?n=3`).
- **پرداخت:** مبلغ همیشه از پایگاه داده می‌آید. موفقیت فقط بعد از «Verify» سمت سرور نزد زرین‌پال ثبت می‌شود. تابع `finalize_order` تکرارپذیر است و پورسانت را فقط یک بار می‌دهد.
- **پورسانت:** ۲۰٪ مبلغ پرداخت‌شده؛ در دفتر حساب (`wallet_ledger`) ثبت می‌شود. واریز بانکی فعلاً دستی است.
- نام و رایگان‌بودن فصل‌ها: `config.js` (نمایش) و جدول `chapters` (امنیت). قیمت‌ها و درصد پورسانت: جدول `settings`.
