# راهنمای اجرا، انتشار و دامنه

## اجرا روی کامپیوتر
فایل `index.html` را با دوبار کلیک باز کن. (نیازی به نصب چیزی نیست.)

## انتشار روی GitHub Pages
1. این بسته را باز کن و **محتوای** آن را در مخزن `riazi-dovom-8-fasl` آپلود کن (فایل‌های قبلی با همین نام جایگزین می‌شوند).
2. فایل‌های `ch3.html` تا `ch8.html` را از مخزن **حذف کن** (فایل را باز کن، آیکون سطل زباله، Commit). اگر نکنی، همچنان برای همه باز هستند.
3. Settings > Pages > Deploy from a branch > main > /(root).
توجه: تاریخچهٔ مخزن عمومی، نسخه‌های قبلی فایل‌های فصل ۳ تا ۸ را نگه می‌دارد. اگر مهم است، مخزن تازه بساز.

## اتصال دامنه
1. دامنه را از یک ثبت‌کننده بخر.
2. در Settings > Pages > Custom domain دامنه را وارد و Save کن.
3. در DNS دامنه، برای دامنهٔ اصلی چهار رکورد A بساز: `185.199.108.153` و `185.199.109.153` و `185.199.110.153` و `185.199.111.153`. برای `www` یک CNAME به `zafa0981-prog.github.io` بساز.
4. بعد از فعال‌شدن، «Enforce HTTPS» را بزن. (این مقادیر را طبق مستندات رسمی GitHub هم دوباره چک کن.)

## تغییر فصل‌ها
نام، رنگ و رایگان/قفل بودن هر فصل فقط در `config.js` است.
